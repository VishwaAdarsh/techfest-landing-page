## 1. Project Overview & Architectural Principles

This redesign delivers a premium, exceptionally smooth cyber-technology festival website for **Techfest, IIT Bombay** (Asia's Largest Science & Technology Festival).

### Zero 3D Asset Constraint (100% Adhered to)
- **No Three.js**, **no WebGL**, **no React Three Fiber**, **no Blender renders**, and **no 3D models or object scenes**.
- Pure **HTML5**, **CSS3**, **React 19**, **TypeScript**, **SVG mathematical animations**, **Web Audio API**, **GSAP**, and **ScrollTrigger**.
